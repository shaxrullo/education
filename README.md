# 📚 Education

**Education** — Flutter yordamida ishlab chiqilgan zamonaviy va qulay ta'lim platformasi mobil ilovasi. Ilova foydalanuvchilarga ta'lim kontentidan foydalanish, testlarni ishlash va natijalarini ko'rish uchun qulay interfeys taqdim etadi.

## ✨ Asosiy imkoniyatlar

* 🔐 Sign In / Sign Up
* 📚 Ta'lim kurslari
* 📝 Test va quiz tizimi
* 📊 Test natijalarini ko'rsatish
* 🎯 To'g'ri va noto'g'ri javoblarni hisoblash
* 📱 Responsive UI
* 🎨 Zamonaviy va minimal dizayn
* 🧭 Qulay navigatsiya
* 📐 Turli ekran o'lchamlariga moslashuvchan interfeys

## 🎨 UI/UX Design

Ilovaning asosiy UI/UX dizayni zamonaviy, minimal va foydalanuvchiga tushunarli bo'lishiga e'tibor qaratilgan.

Interfeysni ishlab chiqish jarayonida **AI vositalaridan yordamchi sifatida foydalanildi**. AI yordamida ayrim UI g'oyalari, komponentlar va dizayn yechimlari ishlab chiqildi hamda loyiha talablariga moslashtirildi.

> AI loyiha yaratish jarayonida yordamchi vosita sifatida ishlatilgan, yakuniy kod va UI yechimlari loyiha ehtiyojlariga mos ravishda ishlab chiqilgan va tahrirlangan.

## 🚀 Installation

Loyihani kompyuteringizga yuklab oling:

```bash
git clone https://github.com/shaxrullo/education.git
```

Loyiha papkasiga o'ting:

```bash
cd education
```

Dependencylarni o'rnating:

```bash
flutter pub get
```

Ilovani ishga tushiring:

```bash
flutter run
```

## 📋 Requirements
